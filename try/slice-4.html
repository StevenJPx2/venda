Slice 4 · Content on GitHub

A deployed Venda reads its content from a GitHub repository and publishes by committing to it, credited to whoever pressed Publish. A push made by someone else is never written over.

Start Venda on a repository

Checking where the content comes from…

Stop pnpm try and start it with pnpm try --github. Venda then reads try/content from a simulated GitHub repository on this machine, through the same GitHub App sign-in, Git trees and conditional commits it uses against github.com. Nothing leaves your machine.

  1. Open the admin ↗, edit an entry and press Publish changes.
  2. The commit appears below, with its message and author. Press Refresh to see it.
